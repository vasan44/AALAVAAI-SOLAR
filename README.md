# Rehoboth Solar Next.js Website

Professional Next.js website for Rehoboth Solar & Electrical Service with:

- React public landing page
- Quote request form
- PostgreSQL-backed leads API
- Password-protected admin panel at `/admin`
- Local generated hero image asset

## Setup

```bash
npm install
cp .env.example .env.local
```

Create a PostgreSQL database, update `DATABASE_URL`, then run:

```bash
psql "$DATABASE_URL" -f db/schema.sql
npm run dev
```

Open `http://localhost:3000`.

## Admin

Set `ADMIN_PASSWORD` in `.env.local`, then open `/admin` and enter that password to load and update leads.
